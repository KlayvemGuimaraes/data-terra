# GreenSite DC

Protótipo estático para o hackathon: inteligência territorial para avaliar
regiões candidatas a data centers de IA no Brasil.

## Como abrir

Abra `index.html` no navegador.

## O que o MVP demonstra

- Mapa do Brasil com hotspots de aptidão.
- Score territorial ponderável pelo usuário.
- Camadas inspiradas na PID: energia, infraestrutura, água e risco.
- Ranking de regiões candidatas.
- Recomendações e condicionantes para decisão de investimento/licenciamento.

Os dados são simulados e servem para demonstrar a lógica do produto, não para
tomada de decisão ambiental oficial.
